# 菠萝文案

从当前代码整理。问候、天气、就寝在 `src/ui/shell.ts`，带路台词在 `src/game/tour-lines.ts`，歌名在 `src/game/catalog.ts`，衣柜在 `src/game/outfits.ts`。

称呼是「菠萝丁」。第一次见面会说做朋友，之后改说又见面了。

## 见面

按时段打招呼，拼在自我介绍前面。

| 时段 | 招呼 |
| --- | --- |
| 清晨 | 早上好~菠萝丁 |
| 正午 | 中午好~菠萝丁 |
| 黄昏 | 下午好~菠萝丁 |
| 夜晚 | 晚上好~菠萝丁 |

第一次见面，招呼后面接：

> 我是甜美可爱的菠萝，今天开始我们做朋友吧～

第二次及以后：

> 又见面了菠萝丁

接着说：

> 闻到了吗？我身上有点甜甜的菠萝香。跟着这个味道，慢慢吸——慢慢呼——。我就在这儿，陪你一起慢下来，给好心情续个航～

没在导览里时，再问一句，并给出确定 / 取消：

> 跟我一起，四处走走，看看风景吧。

## 换时段

时段切过去时说一句。

| 时段 | 台词 |
| --- | --- |
| 清晨 | 早呀——露水刚给我皇冠上的叶子洗过脸，太阳正踮着脚尖，亲吻我的脸颊 |
| 正午 | 正午的光最直，也最诚实——我要被晒成菠萝干了 |
| 黄昏 | 黄昏把天染成了菠萝糖浆的颜色，云在慢慢化开，你也别急着赶路。 |
| 夜晚 | 夜深了，星星是撒在天上的菠萝丁——数着数着，就把今天轻轻放下了。 |

## 天气

晴和多云不说话。雨、风、雾各三档，档位从低到高对应下面三句。

**雨**

1. 雨在给我梳头呢——一根一根，轻轻的。
2. 雨是天空在写长信，字迹有点急，但每一滴都认得你的窗。
3. 雨把世界泡成了一罐菠萝糖水，咱们躲在罐子里，听外面咕嘟咕嘟。

**风**

1. 风路过时摸了摸我的叶子冠，没说话，但意思到了。
2. 风在街角翻跟头，把菠萝的香气吹给三条街外的蒲公英了。
3. 风不讲道理，但你要记得——它吹不倒一颗心里有甜味的果子。

**雾**

1. 云朵掉下来了一角，软软地搭在肩膀上，别抖落它。
2. 雾把路藏起来了一半，剩下的那一半，刚好够我们慢慢走。
3. 雾里什么都看不清——除了我的小肚皮，它是亮亮的。

## 就寝

每天夜晚 22 点提醒一次：

> 22点啦——星星都回窝了，菠萝丁，我不催你，只提醒一句：被子已经替你暖好了，就差你了~

## 带路

连续走动后，菠萝问要不要换地方，按钮是「否 / 是」：

> 我圆滚滚地走到你脚边啦——要不要，去其他地方转转？我带路，你跟着，咱们谁也不许落下谁

跟着走的时候，每换一首歌说一句。找不到对应歌时用这句：

> 菠萝丁，我先滚一小段。你跟着我的圆脚印，谁也不许落下谁。

自己走进导览的那一首不说带路台词。
